# WT-4 — ASP.NET Core MVC «MeloWave // УИР ЭДИШИОН »

Вариант 13: музыкальный сервис для поедания ШАУРМЫ. Проект продолжает предметную область лабораторной WT-3 (`Track`) и реализует серверное веб-приложение на ASP.NET Core MVC (.NET 8).

## Возможности

- главная страница и адаптивный интерфейс на Bootstrap 5;
- каталог из семи демонстрационных треков;
- просмотр карточки трека;
- добавление и редактирование записей через GET/POST;
- поиск по названию, исполнителю и альбому;
- фильтрация по жанру и сортировка по названию, исполнителю, популярности и году;
- проверка вводимых данных через DataAnnotations и сообщения в Razor Views;
- обработка отсутствующих ID с ответом `404 Not Found`;
- Dockerfile для публикации в Render Web Service.

## Запуск локально

Требуется установленный .NET 8 SDK.

```bash
dotnet restore
dotnet run --project wt-lab4-4mvc-popko.csproj
```

При использовании приложенного профиля запуска сайт будет доступен по адресу `http://localhost:5108`.

## Структура

- `Models/Track.cs` — модель музыкального трека и правила валидации;
- `ViewModels/TrackIndexViewModel.cs` — данные каталога и параметры фильтрации;
- `Controllers/HomeController.cs` — главная страница и обработка ошибок;
- `Controllers/TrackController.cs` — каталог, Details, Create и Edit;
- `Views/` — Razor-представления и общий шаблон `_Layout.cshtml`;
- `wwwroot/` — CSS, JavaScript и локальная SVG-иллюстрация;
- `Dockerfile` — сборка и запуск контейнера для Render.

База данных не используется. Треки хранятся в статической коллекции в памяти процесса; изменения сбрасываются при перезапуске приложения.

## Проверка маршрутов

- `/` — главная страница;
- `/Track/Index` — каталог;
- `/Track/Details/1` — карточка первого трека;
- `/Track/Create` — форма добавления;
- `/Track/Edit/1` — форма редактирования первого трека.

## Docker

Из каталога проекта выполните:

```bash
docker build -t melowave-wt4 .
docker run --rm -p 10000:10000 -e PORT=10000 melowave-wt4
```

Затем откройте `http://localhost:10000`.

## Публикация на Render

1. Создайте репозиторий GitHub `wt-lab4-4mvc-popko` и отправьте в него файлы проекта.
2. В Render выберите **New → Web Service**, подключите GitHub-репозиторий и укажите Runtime/Language **Docker**, ветку `main`.
3. В разделе Environment можно оставить стандартный `PORT=10000` (или задать `10000`). Приложение слушает `0.0.0.0:$PORT`.
4. Дождитесь успешных Build и Deploy Logs, откройте выданный адрес `https://<имя-сервиса>.onrender.com` и проверьте маршруты из раздела выше.
5. Вставьте реальные URL в этот README и отчёт, а также добавьте фактические скриншоты Render Dashboard и опубликованного сайта.
